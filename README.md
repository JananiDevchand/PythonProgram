# Odd or Even Program

This repository contains a simple Python program that checks whether a given number is odd or even.

## Logic of the Code
- The program defines a function `check_odd_even(number)` that takes an integer as input.
- It uses the modulus operator `%` to determine if the number is divisible by 2.
- If the result is 0, the number is even; otherwise, it is odd.
- The program prompts the user to enter a number and prints the result accordingly.
